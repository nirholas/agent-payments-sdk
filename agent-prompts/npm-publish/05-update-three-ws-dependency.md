# Task: Update three.ws to use @nirholas/agent-payments-sdk from npm

## Context

- three.ws repo: `/workspaces/three.ws`
- `@nirholas/agent-payments-sdk@0.2.0` is now published to npm (prerequisite)
- three.ws currently uses a workspace dependency: the `agent-payments-sdk/` folder at `/workspaces/three.ws/agent-payments-sdk/` with the old name `@pump-fun/agent-payments-sdk`
- Goal: switch to `@nirholas/agent-payments-sdk` from the npm registry

---

## Step 1: Read current state

```bash
cat /workspaces/three.ws/package.json
```

Note the `workspaces` array and the `agent-payments-sdk` entry. Note how `@pump-fun/agent-payments-sdk` is currently referenced.

Also check what name the local workspace package has:
```bash
cat /workspaces/three.ws/agent-payments-sdk/package.json | grep '"name"'
```

---

## Step 2: Find all imports of the old package

Search the entire three.ws codebase for imports from the old package name:

```bash
grep -r '@pump-fun/agent-payments-sdk' /workspaces/three.ws --include="*.js" --include="*.ts" --include="*.svelte" --include="*.mjs" -l 2>/dev/null | grep -v node_modules | grep -v agent-payments-sdk/
```

```bash
grep -r '@pump-fun/agent-payments-sdk' /workspaces/three.ws --include="*.json" -l 2>/dev/null | grep -v node_modules
```

Record every file that imports from `@pump-fun/agent-payments-sdk`.

---

## Step 3: Update package.json

Edit `/workspaces/three.ws/package.json`:

1. Remove `"agent-payments-sdk"` from the `workspaces` array.
2. In `dependencies` (or wherever `@pump-fun/agent-payments-sdk` appears), replace with:
   ```json
   "@nirholas/agent-payments-sdk": "^0.2.0"
   ```
3. Remove `@pump-fun/agent-payments-sdk` entirely.

The workspaces array should change from:
```json
"workspaces": [
  "agent-payments-sdk",
  "character-studio"
]
```
to:
```json
"workspaces": [
  "character-studio"
]
```

(Remove `"agent-payments-sdk"` only. Keep `"character-studio"` and any others.)

---

## Step 4: Update all import statements

For each file found in Step 2, replace every occurrence of `@pump-fun/agent-payments-sdk` with `@nirholas/agent-payments-sdk`.

Use the Edit tool with `replace_all: true` for each file.

Example: if `/workspaces/three.ws/api/_lib/agent-pumpfun.js` contains:
```js
import { PumpAgent } from '@pump-fun/agent-payments-sdk/solana';
```
Change to:
```js
import { PumpAgent } from '@nirholas/agent-payments-sdk/solana';
```

The subpath exports (e.g. `/solana`, `/evm`, `/x402`) are identical between the old and new packages — only the scope prefix changes.

---

## Step 5: Remove the vendor lock file reference

Check if there's a `package-lock.json` or `npm-shrinkwrap.json` that pins the workspace:
```bash
grep -n 'agent-payments-sdk' /workspaces/three.ws/package-lock.json | head -20
```

The lock file will be regenerated by `npm install`, so no manual edits needed.

---

## Step 6: Install dependencies

```bash
cd /workspaces/three.ws && npm install 2>&1
```

This will:
- Remove the workspace link to `agent-payments-sdk/`
- Install `@nirholas/agent-payments-sdk@^0.2.0` from npm
- Regenerate `package-lock.json`

If install fails with a resolution error, check that the package is published:
```bash
npm show @nirholas/agent-payments-sdk version
```

## Step 7: Verify the import resolves

```bash
cd /workspaces/three.ws && node --input-type=module <<'EOF'

  console.log('solana exports:', Object.keys(m).slice(0, 5));

EOF
```

Also test CJS (the three.ws API runs in Node):
```bash
cd /workspaces/three.ws && node -e "
const m = require('@nirholas/agent-payments-sdk');
console.log('CJS exports:', Object.keys(m).slice(0, 5));
" 2>&1 || echo "(CJS test skipped — package is ESM-only, that is OK for Vercel edge functions)"
```
